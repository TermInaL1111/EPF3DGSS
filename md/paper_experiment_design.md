# 面向 CCF A/B 投稿的研究设计

## 研究问题与原创贡献

核心问题是：几何蒸馏已经能从事件预测深度和相机，怎样利用这些预测，在没有源 RGB、源真值位姿和逐场景优化的条件下，生成多视图一致、可直接渲染的新视角？论文要证明具体机制的收益。当前证据支持把“事件几何到前馈 3DGS”作为研究问题，原创方法仍需验证。

| 组件 | 当前归属 | 需要的证据 |
|---|---|---|
| 共享 K 最终 token 蒸馏、LoRA、SAAG | Déjà-Events 的论文复现与 DSEC 适配 | 作为基线，固定训练预算和 K 采样 |
| REALM 掩码、F³ 特征 | 已有方法的迁移与组合 | 固定其他条件，验证各组件和交互 |
| 固定中心 Gaussian head | 已实现的项目基线。结合 EvGGS 的强度与形状分支、InfiniSplat v2 的固定中心、AnySplat 的几何与外观融合 | 与旧头做同骨干对照，固定输入与训练预算 |
| **事件触发约束下的点图到高斯重建** | 均匀体素融合对照已实现，事件触发监督待接入 | 先分离检验事件物理监督和三维融合的贡献，再决定是否将源事件证据用于融合 |

## 点图到高斯的主创新设计

**主模型先在三维空间融合点图特征，再按表面组预测高斯。** 单目各源帧的像素只提供点图采样和局部特征。DPT 负责把多层 token 解码成与点图对齐的密集特征。最终 Gaussian MLP 作用在融合后的三维表面组上。当前已运行的逐像素固定中心头保留为对照。

### 参考方法的区别

| 方法 | 何时融合 | 高斯输出 |
|---|---|---|
| DA3-GS | 逐像素 Gaussian head 是此处对照 | DPT 解码后的逐像素属性。 [InfiniSplat v2 §3.1](https://arxiv.org/html/2610.20341v1#S3.SS1) |
| InfiniSplat v2 | 先得到像素级高斯候选及属性，再做体素合并和透明度剪枝 | 最终渲染使用体素合并后的高斯。 [InfiniSplat v2 §3.2](https://arxiv.org/html/2610.20341v1#S3.SS2) |
| AnySplat | DPT 产生像素对齐的属性和置信度，再做置信加权的体素融合 | 启用体素化时，最终是体素级高斯。 [AnySplat §3.2](https://arxiv.org/html/2505.23716v2#S3.SS2) |
| VG²GT | DPT 将特征对齐到稠密点图，再把特征汇聚到细体素，随后用 PointMLP 增强 | 从每个细体素特征回归一个或多个高斯。 [VG²GT §3.2.2](https://arxiv.org/html/2606.01573v1#S3.SS2.SSS2) |

### 事件物理约束

事件 `e_k=(u_k,t_k,p_k)` 表示像素 `u_k` 的对数亮度 `L=log I` 相对该像素上次触发后的参考值变化到阈值，极性 `p_k` 记录变化方向。正负阈值 `C_+, C_-` 可以不同。理想模型下，同一个传感器像素在区间 `(t_a,t_b]` 的变化近似为 `C_+ n_+ - C_- n_-`。区间端点通常不在触发时刻，因此还有参考亮度未跨阈值的余项。这个关系只约束亮度变化，整张图的对数亮度加同一个常数仍给出相同差分。 [ESIM](https://proceedings.mlr.press/v87/rebecq18a.html) · [EventNeRF](https://openaccess.thecvf.com/content/CVPR2023/html/Rudnev_EventNeRF_Neural_Radiance_Fields_From_a_Single_Colour_Event_Camera_CVPR_2023_paper.html)

**运动补偿是几何变换。** 同一静态边缘会因相机移动在不同时间触发不同像素。在给定相机运动和深度的情况下，可以把这些事件沿估计轨迹扭到同一个参考时刻。对齐正确时，边缘事件会集中，给对应关系提供证据。深度、姿态或遮挡判断不准时，这个证据也会变差。运动补偿可用作冻结点图的诊断或融合权重对照。事件触发损失则在同一个传感器像素上比较两个时刻的亮度变化和原始事件计数。 [对比度最大化](https://openaccess.thecvf.com/content_cvpr_2018/html/Gallego_A_Unifying_Contrast_CVPR_2018_paper.html)

| 已有工作 | 可复用的设计 |
|---|---|
| EventNeRF、E-NeRF | 比较渲染的对数亮度差和观测事件。EventNeRF 也采样低活动像素。 [EventNeRF](https://openaccess.thecvf.com/content/CVPR2023/html/Rudnev_EventNeRF_Neural_Radiance_Fields_From_a_Single_Colour_Event_Camera_CVPR_2023_paper.html) · [E-NeRF](https://arxiv.org/abs/2208.11300) |
| EventSplat | 在高斯渲染中使用对数亮度变化约束，并从运动轨迹采样时间段。该论文将其用于场景优化。 [EventSplat](https://openaccess.thecvf.com/content/CVPR2025/html/Yura_EventSplat_3D_Gaussian_Splatting_from_Moving_Event_Cameras_for_Real-time_Rendering_CVPR_2025_paper.html) |
| Robust e-NeRF | 说明正负阈值、不应期与噪声会影响事件计数，尤其是在快运动和弱光中。 [Robust e-NeRF](https://arxiv.org/html/2309.08596) |

### 拟验证的机制

**优先验证事件触发约束对前馈高斯的作用。** 冻结 DVLT，先把点图和 DPT 特征在三维中融合，再由共享 MLP 按表面组预测高斯。先实现均匀体素特征融合和深度置信度融合两条对照。关闭任何基于事件的融合权重，单独比较灰度监督与灰度加事件触发监督。固定高斯预算和训练时长，检查事件约束对灰度、透明度和新视角性能的作用。事件触发损失在已有工作中已有先例。它在这里首先是训练约束，创新主张需要进一步证据。

- **训练时的事件差分。** 在同一相机的可同步时间段内，选择 `t_a,t_b`，沿同一轨迹渲染同一高斯场景两次。在原始传感器像素上累积区间中的 `n_+` 和 `n_-`，用稳健损失比较 `log(Î_b+ε) − log(Î_a+ε)` 与 `C_+ n_+ − C_- n_-`。若场景在整流域渲染，将渲染值采回原始像素坐标再做比较，并遮掉无效视场。事件损失以线性强度或显式传感器响应为基础。直接把经过自动曝光、色调映射或伽马编码的灰度图当作线性强度会改变差分。保持原始时间边界和极性，DVLT 的归一化体素仅作网络输入。训练用已知轨迹对齐渲染，验证和推理的构建阶段仅用源事件及预测几何。
- **无事件和阈值。** 统计原始正负计数。仅当 `n_++n_-=0` 时才标记为无事件。对可靠像素可用阈值区间惩罚过大的亮度变化，作为后续对照。低光、热像素和不应期使真实的未触发与理想模型有偏差。先用训练划分独立估计或验证每传感器的固定正负阈值，报告其敏感性。跨域评估禁止借测试 RGB、目标事件或测试序列拟合阈值。保留留出灰度帧的渲染监督以提供亮度参考。
- **数据入口。** MVSEC 先用航线 4 的左相机时间段训练，航线 1–3 留出。首轮选同一传感器上两个已知时间戳和对应的事件段，记录插值与有效视场。DSEC 独立使用经同步核验的轨迹，单列可用子集。EventScape 在读取原始事件极性、时间单位、相机标定和模拟器阈值后再接入。事件监督窗口只用于训练或作为独立评估标签，留出目标事件不进入构建新视角场景的输入。
- **候选创新。** 若触发约束能区分可靠和不可靠的表面，才继续研究把它用于三维分组后的跨视图特征融合。先由深度一致性和可见性决定候选是否同面，再验证事件证据是否改善组内外观权重。运动补偿集中度是可替换的几何证据，优先与原始事件密度做同预算对照。使用光度残差构造推理权重的版本必须只读源事件与源渲染，保持固定前馈计算，避免把目标事件或逐场景优化带入结果。

### 最小实验与论文判据

| 对照 | 要回答的问题 |
|---|---|
| 逐像素固定中心 → 等预算均匀体素特征融合 → 深度置信度融合 | 三维融合和通用置信度各有什么收益？ |
| 同一三维 head，灰度监督 → 灰度加事件触发监督 | 事件物理关系是否改善新视角，并降低留出区间的事件差分误差？ |
| 正常事件监督 → 保持每像素整段正负计数、打乱子窗口时间 → 翻转极性的监督 | 收益是否来自正确的异步时间和极性对应？ |
| 深度置信度 → 原始事件密度 → 运动补偿证据 | 后续若引入事件融合，时空一致性是否优于简单密度？ |

同一冻结骨干、源和目标窗口、最终高斯数量、坐标对齐、步数和每步渲染预算。按视角差、遮挡、运动幅度和事件密度分组。主报 PSNR、SSIM、LPIPS、渲染深度误差、覆盖率、建图时间和显存。另报留出事件区间的物理残差，区分训练用了标定轨迹与构建使用预测源位姿。先在 MVSEC 做同协议控制，再跨数据域验证。当前已实测的是固定中心 head，物理约束和三维融合仍是拟验证方案。

## SAAG 的实际实现

当前使用 NVIDIA 公开 DVLT 骨干，以 Déjà-Events §III-C、图 3 为规格独立实现 SAAG。当前实验没有使用作者的 SAAG 源码或权重。引用时标注 **our reimplementation from the paper**。

- 将五时间 bin 事件体素归一化后取绝对活动图，在 DVLT 的 12×16 patch 网格做均值池化，再除以每视图最活跃 patch。密度在一轮 K 次递推中固定。当前聚合顺序、分辨率和归一化以本地代码为准。
- frame/global attention 各有一个本地 MLP。输入为 patch 密度和区间两端的 DVLT 正弦嵌入，维度为 129，经 16 维 SiLU 隐层回归两项修正。末层零初始化，使初始修正为零。
- 注意力和 FFN 残差的门分别乘 (1+c_{attn})、(1+c_{ffn})，输出门保留 DVLT 形式。相机与 register token 的修正为零。两支原始 step gate 的投影可训练。当前实现未对修正加额外数值约束。
- 两个正在跑的 F³ 实验都启用了 SAAG 与 REALM。它们测量 F³ 在蒸馏输入与 Gaussian head 中的联合效果。SAAG 单独的对照应固定 F³、REALM、共享 K 采样和预算，比较冻结调度、解冻调度、解冻加 patch 门。主报 K=16，再扫 K=8、12、16、20、24。先用相同步数筛选，关键结论用完整预算与多种子复查。

实现入口见 [event_dvlt.py](../event_dvlt.py#L65)、[train_dsec.py](../train_dsec.py) 和 [Déjà-Events §III-C、表 VI](https://arxiv.org/html/2611.21302v1)。表 VI 的完整门控相对直接蒸馏，AbsRel 从 0.147 到 0.144，ATE 在报告精度下相同。论文里的 K 扫描还受训练 K 分布影响。

## 论文主张需要的实验

1. 完成有/无 F³ 的全量几何与 NVS 表。报告匹配事件、空事件、同条件乱序事件，以及独立训练种子的稳定性。先导中 F³ 改善深度和点图、位姿 AUC 下降，当前没有最终 NVS 证据。
2. 用固定骨干组合 F³ 蒸馏开关与 GS 外观 F³ 开关，形成 2×2，区分几何与外观贡献。固定中心和旧头也需同骨干对照。
3. 在同一三维 head 上先验证灰度加事件触发约束，再检验可选的事件融合权重。控制高斯数量、预算、相机和训练划分，报告质量、运行时间及退化案例。
4. 先补共同窗口的教师和直接蒸馏，接着补 EventScape 同训练域和 MVSEC 室外跨域。IncEventGS 同数据实跑留到后续。最终论文使用有可核验配置、数据划分、权重和逐窗口产物的结果。

### EventScape 归档核验

服务器有三个 ZIP，共约 99 GiB。训练集 Town01–03 有 527 条序列、122,329 帧，Town05 验证集有 100 条序列、22,493 帧，Town05 测试集有 116 条序列、26,183 帧。三组序列键无交集。全量检查了 RGB、事件、深度的帧索引、成员文件和时间戳表。每序列首、中、尾各读一个事件包，确认 `x/y/p/t` 位于 512×256 像素网格、极性为 0/1、时间为绝对微秒，常规包最长约 40 ms。车辆位姿时间表覆盖帧时刻，最近样本偏差在 1 ms 以内。官方页面给出 256 px 焦距。相机安装外参和 CARLA 到相机的位姿变换待核验，再发布点图、ATE 与 AUC。 [EventScape 官方发布](https://rpg.ifi.uzh.ch/RAM_Net.html)

Déjà-Events §IV-B 指定 Town01–03 训练、Town05 的 116 条测试序列。首轮本地直接蒸馏采用 20,000 步、冻结步进门控、无 F³、无 REALM 掩码，2–18 个连续单目时间视图之间采样。模型用各自对应的原始事件包和 RGB，二者缩放到同一 224×168 DVLT 网格。两步联调实际用了 10 视图，训练标签为冻结 RGB 教师 token。训练和验证直接读 ZIP。队列 `epf-eventscape-direct.service` 等 GPU 1 的 MVSEC 对照释放显卡后启动。Town05 测试分成 1,368 个不重叠的 18 视图窗，先测 200 m 上限内的 AbsRel 和 δ1，同窗跑 RGB DVLT 教师，原生网格上按窗用中位深度比定尺度。 [Déjà-Events §IV 和表 VI](https://arxiv.org/html/2611.21302v1)

EventScape 论文 §IV-A 说明模拟器从 500 Hz 渲染图产生事件，逐序列从 0.15–0.25 采样对数亮度阈值，并设置 100 µs 不应期。发布的 RGB 为 25 Hz。阈值区间可作为训练实验的先验。正式加入事件损失前，先在 Town01–03 核对发布 RGB 的亮度响应与带极性的原始计数，报告误差对阈值与时间分段的敏感性。 [EventScape 论文](https://rpg.ifi.uzh.ch/docs/RAL21_Gehrig.pdf)

### MVSEC 三维体素高斯对照

`--head voxel` 取 DVLT 四个递归阶段的特征，逐级上采样并合并外观特征。由预测深度与相机得到三维候选点，在边长 5 cm 的体素内平均点坐标和特征，再从每个占据体素回归一组高斯属性。实验沿用单目 MVSEC 航线 4 训练、航线 1–3 验证，冻结 DSEC 无 F³ 蒸馏几何。训练使用已知源相机，以对应原固定头的训练条件。验证使用 DVLT 预测源相机。两步联调用两张源点图，在抽查窗口中生成 278 个高斯，训练和渲染均可执行。5,000 步任务 `epf-mvsec-voxel-no-f3.service` 完成后生成和固定头相同的 72 窗共享评测，记录 PSNR、SSIM、LPIPS 与高斯数量。此对照只用灰度监督，事件触发监督和遮挡感知融合属于后续的独立消融。
