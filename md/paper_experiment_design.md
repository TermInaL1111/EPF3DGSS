# 面向 CCF A/B 投稿的研究设计

## 研究问题与原创贡献

核心问题是：几何蒸馏已经能从事件预测深度和相机，怎样利用这些预测，在没有源 RGB、源真值位姿和逐场景优化的条件下，生成多视图一致、可直接渲染的新视角？论文要证明具体机制的收益。当前证据支持把“事件几何到前馈 3DGS”作为研究问题，原创方法仍需验证。

| 组件 | 当前归属 | 需要的证据 |
|---|---|---|
| 共享 K 最终 token 蒸馏、LoRA、SAAG | Déjà-Events 的论文复现与 DSEC 适配 | 作为基线，固定训练预算和 K 采样 |
| REALM 掩码、F³ 特征 | 已有方法的迁移与组合 | 固定其他条件，验证各组件和交互 |
| 固定中心 Gaussian head | 已实现的项目基线。结合 EvGGS 的强度与形状分支、InfiniSplat v2 的固定中心、AnySplat 的几何与外观融合 | 与旧头做同骨干对照，固定输入与训练预算 |
| **跨视图可靠性引导的事件高斯融合** | 拟研究的主创新，尚未实现或验证 | 在相同候选和高斯预算下，对比无融合、均匀融合、只用深度置信度、加入事件和跨视图一致性的完整版本 |

主创新候选从一个可证伪的假设出发：稀疏事件使单视图外观不完整，同时预测位姿和深度误差会制造重复表面。基于冻结几何，在共同坐标系匹配候选高斯，用可见性、深度与重投影一致性估计几何可靠性，用局部事件时间支持和 F³ 描述外观可靠性。融合时分别控制几何支持和外观贡献，留下无跨视图支持但可能真实的表面。风险是低事件区域或遮挡边界被误抑制，或者收益仅来自减少高斯。按事件密度、视角基线和遮挡分组报告，记录候选数量、保留数量和显存。若等预算对照无法支持机制，保留实测结果并收缩主张。体素融合和置信加权已有先例，需验证事件证据和跨视图一致性带来的增量。 [EvGGS](https://arxiv.org/html/2405.14959v1) · [InfiniSplat v2](https://arxiv.org/html/2610.20341v1) · [AnySplat](https://arxiv.org/html/2505.23716v2) · [当前 Gaussian head](gaussian_head.md)

## SAAG 的实际实现

当前使用 NVIDIA 公开 DVLT 骨干，以 Déjà-Events §III-C、图 3 为规格独立实现 SAAG。当前实验没有使用作者的 SAAG 源码或权重。引用时标注 **our reimplementation from the paper**。

- 将五时间 bin 事件体素归一化后取绝对活动图，在 DVLT 的 12×16 patch 网格做均值池化，再除以每视图最活跃 patch。密度在一轮 K 次递推中固定。当前聚合顺序、分辨率和归一化以本地代码为准。
- frame/global attention 各有一个本地 MLP。输入为 patch 密度和区间两端的 DVLT 正弦嵌入，维度为 129，经 16 维 SiLU 隐层回归两项修正。末层零初始化，使初始修正为零。
- 注意力和 FFN 残差的门分别乘 (1+c_{attn})、(1+c_{ffn})，输出门保留 DVLT 形式。相机与 register token 的修正为零。两支原始 step gate 的投影可训练。当前实现未对修正加额外数值约束。
- 两个正在跑的 F³ 实验都启用了 SAAG 与 REALM。它们测量 F³ 在蒸馏输入与 Gaussian head 中的联合效果。SAAG 单独的对照应固定 F³、REALM、共享 K 采样和预算，比较冻结调度、解冻调度、解冻加 patch 门。主报 K=16，再扫 K=8、12、16、20、24。先用相同步数筛选，关键结论用完整预算与多种子复查。

实现入口见 [event_dvlt.py](../event_dvlt.py#L65)、[train_dsec.py](../train_dsec.py) 和 [Déjà-Events §III-C、表 VI](https://arxiv.org/html/2611.21302v1)。表 VI 的完整门控相对直接蒸馏，AbsRel 从 0.147 到 0.144，ATE 在报告精度下相同。论文里的 K 扫描还受训练 K 分布影响。

## 表 A：几何、深度和位姿

- **主指标**。深度 AbsRel、δ1。点图在共同有效像素上 Sim(3) 对齐，报告相对 L2、Inl@25%（Déjà-Events）和 IR@3%（DVLT）。另报有效预测覆盖率、深度范围、对齐的尺度单位。位姿用轨迹中心对齐后的 ATE（m），以及 AUC@3°、20°、30°。同步双目只报相对位姿 AUC，ATE 留空。DSEC 同时保留深度 50 m 上限。
- **Event3R 对照**。其论文深度列是 AbsRel/δ<1.25，重建列是 Acc、Comp、NC，与逐像素对应的点图误差是不同定义。另设点云表，在同样的点数、有效范围和对齐变换下计算双向近邻距离及法向一致性。法向邻域、点采样和对齐在复测前锁定。Event3R 的 MVSEC 训练经历、室外数据、单位随结果一起列出。
- **基线**。每个本地测试窗口运行 RGB DVLT 教师，标为 RGB 参照。优先运行本地直接蒸馏对照；Déjà-Events 与 Event3R 的官方权重或预测产物能核实时再加入同窗表。当前可引用作者发表值和本地复现实验，出处逐行标明。加入 EventVGGT 等可运行的事件几何基线时注明权重训练域。
- **表格列**。方法、训练域、传感器、测试序列、窗口、深度、点图、位姿、复跑/发表来源。相同协议才用相对百分比和排名。误差下降用 ((b-x)/|b|)，准确率上升用 ((x-b)/|b|)，并保留原值。已有跨协议百分比是数值差。

## 论文主张需要的实验

1. 完成有/无 F³ 的全量几何与 NVS 表。报告匹配事件、空事件、同条件乱序事件，以及独立训练种子的稳定性。先导中 F³ 改善深度和点图、位姿 AUC 下降，当前没有最终 NVS 证据。
2. 用固定骨干组合 F³ 蒸馏开关与 GS 外观 F³ 开关，形成 2×2，区分几何与外观贡献。固定中心和旧头也需同骨干对照。
3. 主创新候选和均匀、深度置信融合用相同预算。报告质量、运行时间及退化案例，识别效果来自可靠性机制还是高斯数量变化。
4. 先补共同窗口的教师和直接蒸馏，接着补 EventScape 同训练域和 MVSEC 室外跨域。IncEventGS 同数据实跑留到后续。最终论文使用有可核验配置、数据划分、权重和逐窗口产物的结果。

### EventScape 归档核验

已读取 Town05 验证和测试 ZIP 的目录，分别有 100 和 116 条序列，序列 ID 无交集。两包含 RGB、事件、深度和车辆定位数据。抽查验证序列 139，RGB、事件包与深度的前两个索引及时间戳一致，事件 NPZ 保存 `x/y/p/t`，车辆轨迹另有时间戳、位置和朝向。尚需全量验收样本内容，并核对相机内外参、事件时间单位和车辆到相机变换。Town01–03 训练归档当前仅有下载分片。暂以归档的 val/test 为数据集划分，Déjà-Events 的确切序列选择仍未核实。
